Validator Tanda Tangan Digital

Verifikasi tanda tangan digital dokumen berbasis QR Code dan PASETO v4.public (Ed25519) secara langsung di browser Anda tanpa mengirim kunci atau dokumen ke server mana pun.

Data Verifikasi

Verifikasi menggunakan kunci publik resmi Prodi D4TI ULBI yang tersimpan di aplikasi.

Ambil Token dari QR Code (Opsional)

Arahkan QR Code ke kamera. Pemindaian berhenti otomatis saat token terbaca.

Jika dipilih, hash SHA-256 berkas akan dicocokkan dengan klaim doc_hash di dalam token.
